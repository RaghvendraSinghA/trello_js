# Trello Clone

A vanilla JavaScript Trello-style project that uses the Trello REST API to fetch and manage boards, lists, cards, and checklists.

## Requirements

* Node.js
* npm
* A Trello API key and token

## Installation

Clone the project and move into the project directory:

```bash
git clone <repository-url>
cd trello
```

Install the dependencies:

```bash
npm install
```



## Run the Project

This project contains browser-side JavaScript that uses the DOM, so **do not run the main `script.js` using Node.js**.

Start a local server from the project root.

For example:

```bash
python3 -m http.server 5500
```

Then open:

```text
http://localhost:5500
```


#### You will also need ngrok to make your localhost available to public, then only trello official website will be able to reach the backend.
